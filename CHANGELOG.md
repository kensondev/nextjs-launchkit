## 1.0.0 - 2026-10-29

Initial commercial release of LaunchKit by Kenson Dev.

### Included

- Next.js 16 App Router landing page with TypeScript and Tailwind CSS 4.
- Responsive navigation, hero, brand strip, features, how-it-works section, product preview, testimonials, monthly/yearly pricing display, FAQ, and final call to action.
- Light and dark themes with browser preference persistence and Inter typography.
- Central site configuration for copy, colors, links, pricing, and section visibility.
- Waitlist form, confirmation route, custom 404, and editable privacy and terms pages.
- Metadata, generated social preview, sitemap, and robots directives.
- Server-side waitlist validation, 8 KiB request limit, honeypot, five-request-per-minute IP limit, expired-entry cleanup, and a bounded in-memory limiter.
- Keyless structured console logging, webhook delivery, and Resend audience contact delivery with an eight-second upstream timeout.
- Generic public errors without submitted addresses, credentials, or provider response bodies.
- Environment example, customization and deployment instructions, demo-content disclosure, and a commercial Single Project License.

### Release notes

Provider integration verification is limited to local behavior. Live provider accounts and production hosts require your own end-to-end checks. Console mode is not durable storage. The per-instance in-memory rate limit is not a distributed abuse-protection service.

The dashboard, logos, testimonials, names, metrics, and pricing are illustrative demo content. Authentication, billing, checkout, a database, and a SaaS application backend are not included.
